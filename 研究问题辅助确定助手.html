🧭 模块一 · 大事记梳理 （从事实、概念到研究问题）

① 主语行为体判断

输入研究对象，判断其是否为合格的主语行为体（单体 / 指向性 / 关系性 / 无效）。

② 三时表梳理（首次时间 / 周期时间 / 现状时间）

③ 三事表定位（上位 / 下位 / 平行事件）

🔍 补充真实资料（搜索 / 新闻 / 来源）

本工具无法真正联网。请把你在网上搜到的真实新闻、官方文件、智库报告粘贴到下方，点「更新三时表」让 AI 据此补充/修正（尤其现状时间），使事实更准确、最新。可多次补充。

🔬 模块二 · 研究问题发现 （研究问题 = 所追求的知识 − 现有存量知识）

先在上方「模块一 · 大事记梳理」梳理事实，点击「🚀 送入研究问题发现」即可自动填充下方事件库；也可手动粘贴。本模块将遵循「事实→知识→缺口→主题→问题」逻辑，系统发现具有学术价值的研究问题。

💡 提示：点击右上角「API 设置」配置 API Key（推荐免费 Gemini）。未配置时将使用演示数据。
🧭 两种运行方式任选：
① 一键六步：点下方「🚀 运行完整流程（Phase 1→6）」，自动连续跑完六个阶段；
② 逐步运行：进入每个阶段卡片，点「生成此阶段」单独执行（会自动补跑缺失的前置阶段），适合边看边调。
📎 工作流：上方「模块一 · 大事记梳理」梳理事实 → 点「🚀 送入」自动填充本事件库 → 运行发现研究问题 → 可用 研究问题确认助手（Q=F-C 与三原则）进一步检验与确认。
⚠️ 关于文献建库（Phase 2）的重要说明：本工具是纯前端应用，不会真正联网检索 CNKI / Web of Science 等数据库。文献由 AI 模型基于其训练知识生成（非实时检索结果），所有引用务必在正式使用前自行核对原文。如需真实文献，请在 Phase 2 卡片中粘贴你已收集的真实文献，AI 会优先采用并一并分析。

🧱 Phase 1 · 事实建库（Reality Builder）

对三时三事事件库进行标准化清洗、六维结构化（Time/Actor/Behavior/Condition/Outcome/Evidence）、核心概念提取与现实问题识别，构建事实知识库。

本阶段已改为分批生成：按原文行切批抽取事实（每批 ≤10 条）→ 单独提取核心概念 → 单独识别现实问题。生成时顶部会显示第几批、已完成多少条；某批失败不影响其它批。

尚未运行。可在「输入事件库」点击「运行完整流程」，或点下方「生成此阶段」。

📖 Phase 2 · 文献建库（Literature Builder）

围绕核心概念检索、筛选、分析文献，构建结构化文献知识库、核心文献清单与文献综述。

⚠️ 纯前端无法实时检索学术数据库，文献由 AI 基于其知识生成，请务必核对原文。你也可在下方粘贴自己的真实文献，AI 会一并分析。

本阶段已改为分批生成：先规划文献清单 → 每 3 篇一批逐篇拆解 → 最后单独归纳综述。生成时顶部提示会显示当前批次；某一批失败不会影响其它批，已生成的部分会保留。

尚未运行。请先完成 Phase 1（点「生成此阶段」会自动补跑前置）。

🔗 Phase 3 · 知识映射（Knowledge Mapping）

建立事实—概念、概念—理论、理论—文献、事实—文献之间的关联关系，形成统一知识网络。

本阶段已改为分两段生成：先做概念—理论映射，再按事实分批（每批 12 条）做事实—文献映射，避免几十条事实一次输出被截断。

尚未运行。请先完成 Phase 2（点「生成此阶段」会自动补跑前置）。

🕳️ Phase 4 · 缺口发现（Knowledge Gap Discovery）

对比事实知识与学术知识，识别七类知识缺口（概念/理论/经验/方法/边界/时间/空间），评估其研究价值与可行性。

本阶段已改为分两段生成：先识别缺口清单（含现实依据与文献依据），再单独评估价值与可行性、生成证据矩阵与研究机会。

尚未运行。请先完成 Phase 3（点「生成此阶段」会自动补跑前置）。

🎯 Phase 5 · 主题收敛（Topic Discovery）

以知识缺口为基础，对潜在方向聚类、边界收敛，生成候选研究主题并排序，筛选推荐主题。

尚未运行。请先完成 Phase 4（点「生成此阶段」会自动补跑前置）。

❓ Phase 6 · 研究问题生成（Research Question Discovery）

围绕候选主题，生成六类研究问题（What/Why/How/Comparison/Policy/Prediction），形成标准化研究问题卡（含事实依据、文献依据、推荐理论、研究意义、创新点）。

尚未运行。请先完成 Phase 5（点「生成此阶段」会自动补跑前置）。
